# Navigate incoming and outgoing knowledge links

Use lorevell show <id> to read a note with its outgoing links, derived backlinks and unresolved targets. Backlinks come from declared wiki links, not a graph database or semantic guesses. Search returns bounded one-hop linked context separately from ranked matches; it does not recursively expand the graph.
