# Archive superseded notes and retain original evidence

lorevell archive <id> moves original note bytes into archive/ instead of destroying evidence. Archived Markdown is excluded from active indexing. Dream must preserve removed originals byte-for-byte in an archive or renamed note. Archived evidence is not a fresh consolidation candidate.
