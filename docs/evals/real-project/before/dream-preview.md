# Preview the one-agent launcher before running it

lorevell dream --agent codex --dry-run reports candidate paths and the command without starting an agent. Choose --agent claude for Claude Code. The runtime must already be installed and authenticated; Lorevell does not supply a scheduler service, custom model API or bypass-permission flags.
